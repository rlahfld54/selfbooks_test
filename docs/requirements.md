# 공통 UI v1

이번 작업의 기준은 [공통 UI 시스템 구현 지시서](ui-system-spec.md)이다.
기존 업무 분석은 [source-analysis.md](source-analysis.md)를 유지한다.

- Nuxt/Vue 기반 공통 작업 공간 레이아웃, 재사용 UI 컴포넌트, 홈·일반전표·거래처 데모 구현. 현재 구조는 [프런트엔드 아키텍처](frontend-architecture.md)를 따른다.
- 회사와 사용자는 명시적인 UI 데모 컨텍스트이며 서버 인증·권한으로 사용하지 않는다.
- 실제 전표 저장·분개 검증·신고·편집 그리드는 범위 밖이다.
- 재접속 복원은 사용자/회사별 탭과 활성 탭, 사용자별 밀도/사이드바 설정만 지원한다.
- 자유 입력 검색어·미저장 전표·선택 거래처는 저장하지 않는다.
- 구현·검증 기록: [ui-system.md](ui-system.md).
