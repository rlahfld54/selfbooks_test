
## 매입매출전표 저장 규칙 (2026-11-10 사용자 확인)

- 지원 거래유형은 원본으로 확인된 11 매출 과세, 51 매입 과세다.
- 모든 저장은 미확정(draft) 상태이며 차변·대변 합계가 일치해야 한다. 분개는 2~100행, 각 행의 금액은 양수 정수다.
- 11/51의 부가세 0원은 확인요망이다. 사용자가 명시적으로 확인해야 저장 가능하며 서버에 확인 시점을 기록한다. 영세율·면세 코드에는 이 규칙을 확대하지 않는다.
- 공급가액·세액은 음수/소수 없이 원 단위 정수로 받는다. 합계가 0인 전표는 저장하지 않는다. 음수 수정세금계산서 처리 정책은 별도 확정이 필요하다.
- 열린 회계기간의 전표만 저장/수정/삭제할 수 있다. 확정(posted) 전표는 수정·삭제 불가다.
- 세액 자동 산식/절사 및 거래유형·결제방법별 자동분개는 구현하지 않는다. 회사별 마스터 계정을 선택해 수기 분개한다.
